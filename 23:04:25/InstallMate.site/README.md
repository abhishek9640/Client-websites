# InstallMate.site - Countertop Installation Website

A professional, modern website for a countertop installation service specializing in kitchen and bathroom installations.

## Overview

InstallMate.site is a clean, fast-loading website designed for a USA-based countertop installation business. The site features a sleek, professional design with subtle shadows, hover effects, soft gradients, and modern typography.

## Pages

- **Home**: Features a hero section with CTA, service highlights, and recent projects
- **About**: Company mission, expertise, and installation process
- **Services**: Detailed service offerings with features and benefits
- **Contact**: Contact form and company information
- **Legal Pages**: Privacy Policy, Terms & Conditions, and Cookies Policy

## Features

- Modern, clean design with subtle UI enhancements
- Mobile-first responsive layout
- Fast-loading and optimized for performance
- SEO-friendly with semantic HTML
- Cookie consent functionality
- Lazy-loaded images for better performance
- Smooth animations and transitions

## Tech Stack

- HTML5
- CSS3 (Flexbox & Grid layout)
- Vanilla JavaScript
- Google Fonts (Poppins)
- Font Awesome icons

## Design Elements

- Sleek layout with subtle shadows and section spacing
- Card-style layout for service offerings
- Left-aligned sticky navigation
- Typography-focused design
- Enhanced hover effects

## Browser Compatibility

Tested and optimized for:
- Chrome (latest)
- Firefox (latest)
- Safari (latest)
- Edge (latest)
- Mobile browsers (iOS and Android)

## Setup Instructions

1. Clone or download this repository
2. No build process required - files can be directly uploaded to a web server
3. Update contact information and business details as needed

## SEO Considerations

- Semantic HTML structure
- Meta descriptions on all pages
- Optimized page titles
- Proper heading hierarchy
- Sitemap.xml and robots.txt included
